OOP AutoGrader — Lecturer offline Bulk Grading
==============================================

This folder is separate from student practice. Do not mix installs.

Start
-----
1. Run OOP-AutoGrader-LecturerBulk.exe (preferred) or the .bat fallback.
2. Import a practice rubric pack (.agpack) from the header.
3. Download current-term enrollment IRNs from the website Bulk Grading page
   (CSV or Excel), then Import roster in this app.
4. Drop a Main folder dump and Start Grading.

Notes
-----
- Default local API port: 18003 (student practice uses 18002).
- Last finished batch is retained under data/ until a new run or Clear batch.
- Export results to CSV or Excel from the results table.
- Grades never sync to the website Score/roster.
